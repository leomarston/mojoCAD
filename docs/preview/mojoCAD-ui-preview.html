How it behaves: the AI never edits your drawing directly. It stages a change set, highlights exactly where it will draw in green (amber = modify, red = delete), and you accept or reject — per row or all at once. Accepting commits as one ⌘Z step; rejecting leaves the drawing untouched. For life-safety work it plans first and won’t guess code parameters. You remain the engineer of record.
