How it behaves (the important part): mojoCAD never edits your drawing directly. The AI can only stage a change set, which you preview on-canvas (green = new, amber = modified, red = deleted) and accept per-row or wholesale. Accepting applies the selected operations as a single Ctrl+Z step; rejecting leaves the drawing untouched. For Fire & Life-Safety work it must present a plan and may ask clarifying questions before acting — it won’t guess code parameters. You remain the engineer of record.
